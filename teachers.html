For teachers

lilC is a free C learner for iPhone and the browser. Students write C, press Run, and PicoC interprets the program on the device or in this browser. There is no account and no cloud compiler.

The runtime is PicoC, a small interpreter. It is not GCC or Clang. Most beginner programs work. Some advanced C will not. That limit is the product: a phone-sized subset, with errors written for learners.

This release does not include AI. Files stay on the iPhone or in the student’s browser.

Try it with a class in one click

Open the browser copy. No install. Press Run on the starter file.

Source is at github.com/garrettmichae1/lilc.
