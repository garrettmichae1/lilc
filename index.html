Learn C on your iPhone.

lilC is a local C programming environment. Write a program, run it on the device, and see the output — no account, no cloud compiler, no subscription.

The runtime is PicoC, a small on-device interpreter. It is not GCC or Clang. Most beginner programs work. Some advanced C — a full standard library, or extras only a compiler supports — will not.

Your source files stay in the app on this iPhone. Theme (Light or Dark) is stored in UserDefaults. You can delete a file from Home, or erase all files in Settings.

This first release does not include AI or agents, does not send your code to a cloud service, and does not sell a subscription.
