Learn C on your iPhone.
Or in the browser.

lilC is a local C programming environment. Write a program, press Run, and see the output — no account, no cloud compiler, no subscription.

PicoC is an interpreter, not a compiler. It is not GCC or Clang. C libraries will not work with PicoC.

On iPhone, source files stay in the app. In the browser they stay in this browser. Theme (Light or Dark) is stored locally. You can erase files from Home or Settings.

This first release does not include AI or agents, does not send your code to a cloud service, and does not sell a subscription.
