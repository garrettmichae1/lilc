Edsger is an iPhone and iPad app, with a browser copy for C, for writing and running C, Python, JavaScript and Lua with on-device and optional cloud AI. 2. Not a full compiler

C runs in PicoC, an interpreter. It is not GCC, Clang, or a POSIX environment. Some ISO C features are limited. Python, JavaScript and Lua run in restricted on-device runtimes without package installation. Output of a program is not a guarantee of behavior on other platforms.

Optional cloud AI on iPhone

Settings → BYOK lets you optionally use a personal OpenAI or Anthropic API key. You must have permission to use the key and comply with that provider’s API terms. Your provider bills API usage separately, including model connection tests. Edsger does not sell provider credits or collect those payments. Models, permissions, prices, availability and rate limits are controlled by the provider. BYOK requests go directly from your device to your selected provider and require explicit sharing consent as described in the Privacy Policy. AI output may be incorrect; review generated code and use project restore points when needed. A selected model works through Edsger’s existing tools and runtime limits; external model features do not grant unrestricted computer or file access.

Edsger Pro memberships

The iPhone app offers Edsger Pro and Edsger Pro Plus as monthly auto-renewing subscriptions purchased through Apple. Apple handles billing, renewal, cancellation and refunds under its terms; manage or cancel in your Apple Account settings. Each plan includes a monthly AI allowance for Dijkstra Super Fast (Pro Plus includes three times the Pro allowance), used according to the size of each request and response, not a fixed number of messages. The app shows how much of your allowance remains. Allowances renew with each billing period, do not roll over, have no cash value and are shared across your devices. Each request needs a small safety reserve, so a small part of an allowance may remain unusable. When an allowance is used up or the service is busy, Edsger continues with on-device AI. Pro also includes BYOK and GitHub push. GitHub push sends only files you select to your own GitHub account; GitHub’s terms apply to those repositories. We may change or suspend Dijkstra or the AI provider behind it to keep the service secure and affordable; a change will not reduce an allowance already shown for a paid period.

Image generation and cloud execution use the same membership allowance as Dijkstra, with separate sharing permissions. Choosing Low, Medium or High changes the image cost; no particular number of images or messages is guaranteed. Cloud execution also has a per-period run limit, time and output limits, a fixed runtime/library catalog and no outbound networking. It is intended for short programs and offline previews. An interrupted request may already have incurred provider usage; it is not automatically repeated. Image output is AI-generated, may be inaccurate or similar to another output, and remains subject to the provider’s terms and applicable third-party rights. Review output before publishing or relying on it.
